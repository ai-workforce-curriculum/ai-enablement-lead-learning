# mod-104 — Training Programs, AI Literacy Curriculum, and Prompt-Coaching for Non-Engineers

**Estimated effort:** 20 hours
**Role level:** 45 · **Family:** AI Workforce

This module is the training-program half of the AI Enablement Lead role. [mod-101](../mod-101-role-and-the-org-wide-enablement-operating-model/README.md) built the operating model and surfaced the EU AI Act Article 4 literacy floor; [mod-103](../mod-103-policy-co-authoring-with-governance/README.md) co-authored the policy artifacts the training will teach into. This module builds the full literacy curriculum — foundational modules, role-based playbooks, delivery mix, prompt coaching, measurement stack, and L&D / HR / comms partnership — that turns those foundations into fluency.

## Learning objectives

- Design a foundational-to-advanced AI literacy curriculum segmented by audience and skill level — leadership, operators, specialists, builders — with measurable fluency targets.
- Build role-based playbooks and use-case libraries per function (sales, service, operations, finance, HR, legal, engineering, leadership) with prompt and agent libraries curated by role.
- Design and run workshops, office hours, lunch-and-learns, bootcamps, adoption challenges, use-case spotlights, and self-serve resources — the full training-program delivery cycle.
- Run prompt-engineering coaching for non-engineers at the *coaching* framing — 1:1 sessions, prompt libraries, agent patterns, workshops — with the explicit distinction that IC-level prompt craft defers down to [`ai-assisted-software-engineer`](https://github.com/ai-engineering-curriculum/ai-assisted-software-engineer-learning) (level 20) and [`ai-augmented-analyst`](https://github.com/ai-workforce-curriculum/ai-augmented-analyst-learning) (level 20).
- Instrument fluency growth — pre / post assessments, task-level proficiency rubrics, Josh Bersin AI-in-L&D research-based outcome metrics, Microsoft Work Trend Index benchmarks as reference — so the program defends its budget on more than attendance.
- Partner with HR / L&D / internal communications on delivery; hand down team-scope delivery to [`ai-augmented-team-manager`](https://github.com/ai-workforce-curriculum/ai-augmented-team-manager-learning) (level 40) where that's the right vehicle.
