# Exercise 05 — Workshop and Office-Hours Cadence Plan

**Estimated effort:** 2 hours
**Format:** a cadence plan of 2–3 pages, Markdown or docx, including a visual schedule or table
**Grounding chapters:** [05 — The Delivery Mix](../05-the-delivery-mix.md), [08 — Partnering with HR, L&D, and Internal Comms](../08-partnering-with-hr-ld-and-internal-comms.md)

## Objective

Lay out a **one-year cadence plan** for the organization's training delivery — which workshops run when, which office hours stand up when, which lunch-and-learns land in which quarter, which adoption challenge runs when. The artifact is what your operations analyst will feed into the LMS calendar and what internal comms will build the announcement calendar from.

## Prerequisites

- Chapter 05 read; Chapter 08 skimmed.
- Fluency target map from Exercise 01 in hand.
- Foundational curriculum outline from Exercise 02 is useful (it sets the workshop cohort capacity).
- Chosen organization carried forward from earlier exercises.

## Problem statement

Your exec sponsor has approved the training budget for the year. Your L&D partner is asking for the cadence plan so they can book facilitators, your internal comms partner is asking so they can slot announcements into the corporate calendar, and the champion network wants to know when they will be on the hook to deliver office hours.

You have one shot to lay out a sustainable rhythm that respects the sequencing rule from Chapter 05 — self-serve first, foundational workshops second, office hours third, role-based playbooks fourth, spotlights and lunch-and-learns fifth, challenges sixth, bootcamps seventh — and does not overload any one quarter.

## Requirements

Deliver one plan with the following components.

### 1. Opening scope paragraph (3–5 sentences)

- The organization's in-scope population size (anchor your capacity planning).
- The CoE team shape (named roles and capacities).
- Any active constraints (the LMS is being migrated in Q2; a merger is closing in Q3; the regulated subsidiary has a parallel track).

### 2. The year-view cadence table

A single table showing the year in the four quarters, with rows for each vehicle:

| Vehicle | Q1 | Q2 | Q3 | Q4 |
|---|---|---|---|---|
| Self-serve updates | | | | |
| Foundational workshops (operator cohorts) | | | | |
| Role-based playbook workshops (by function) | | | | |
| Specialist bootcamps | | | | |
| Leadership briefings | | | | |
| Office hours (org-wide) | | | | |
| Office hours (by function) | | | | |
| Lunch-and-learns | | | | |
| Use-case spotlights | | | | |
| Adoption challenges | | | | |
| Fluency assessment windows | | | | |

Each cell names the events (count and type) or indicates "continuous" where appropriate.

### 3. The sequencing rationale

A short paragraph (5–8 sentences) explaining:

- Which vehicle you launched first and why.
- The prerequisite logic — what has to be true before each later vehicle lights up.
- Any deliberate off-pattern decision (e.g., running a challenge earlier than typical because the organization has a deadline).

Reference the sequencing rule from Chapter 05 explicitly.

### 4. Capacity math

A short calculation (bullets, not paragraphs) showing:

- How many facilitator hours each quarter costs.
- Whether the CoE team's capacity (plus borrowed L&D and champion hours) can deliver.
- Where the biggest capacity pinch is and how you mitigate it (fewer cohorts, more hybrid, more champion delegation).

If the plan shows a quarter where capacity is clearly exceeded, cut the plan — do not pretend the math works.

### 5. The partner interfaces

A short section naming:

- Which activities L&D runs, which activities internal comms carries, which activities HR coordinates.
- The three-messages-per-month ceiling to the full org from internal comms (Chapter 08).
- The handoffs to `ai-augmented-team-manager` — which activities are *their* delivery, supported by your kit, not yours.

### 6. Measurement triggers

A short section naming when fluency assessments and scorecard snapshots happen in the year. Typically: a baseline at Q1, a mid-year read at Q2, a full assessment at Q4. Scorecard snapshots feed [mod-106](../../mod-106-outcome-measurement-and-executive-reporting/README.md).

## Starter guidance

- Resist the urge to fill every cell. An empty cell in Q1 for "adoption challenges" is correct if your organization has not yet rolled out the foundational curriculum. An over-stuffed cadence loses credibility fast.
- The weekly / monthly rhythms (office hours, lunch-and-learns, self-serve updates) are the backbone. Everything else sits on top. Get the backbone right first, then layer the quarterly events.
- Capacity math is where plans die. A 500-person organization and a 50,000-person organization look very different in the table; the per-cohort capacity (typically 15–25 operators per workshop) does not scale. Do not plan for mass enrollment in a single cohort.
- Reference the delivery-mix dashboard from Chapter 05 — the plan is the input; the dashboard is the output; they share the same vocabulary.
- If your organization touches the EU, the fluency-assessment window at year-end doubles as the Article 4 evidence-collection moment. Design the window with that in mind.

## Deliverables

- `delivery-cadence-plan.md` (or `.docx`): all six components above.
- A short *risk note* (3–5 sentences) naming the single biggest execution risk in the plan and the mitigation.

## Acceptance criteria

- One page, table-heavy, with at least the year-view cadence table complete for all four quarters.
- Sequencing rationale shows the plan respects the Chapter 05 sequencing rule (or justifies an exception).
- Capacity math is present and credible — the CoE team can actually deliver what the plan says.
- Partner interfaces are named — L&D, internal comms, HR, team managers each have an explicit role.
- Measurement triggers are set — at least one baseline, one mid-year, and one year-end window.

## Stretch goals

- Produce a second version of the plan for a counter-factual scenario (a 25% CoE headcount cut, or a merger doubling the in-scope population) and note where the plan breaks. This is the kind of scenario planning that pays off when a real constraint lands.
- Design the first quarter's week-by-week breakdown as an extra deliverable, so the operations analyst can book the LMS slots directly.
- Author the "no, we are not running X this quarter" communication you would send to a function manager who asks for an off-cycle workshop in week six. The ability to say no gracefully is half of cadence management.
- Compare the cadence of your plan to the Josh Bersin AI-in-L&D framing's recommended practices and note one deliberate divergence.

## Why this exercise matters

A good curriculum delivered badly is worse than a mediocre curriculum delivered well. Cadence is the single biggest determinant of delivery quality — reliable rhythms earn trust; frantic calendars earn tune-outs. Writing the cadence plan with the sequencing rule and capacity math in hand is the move that turns a training program from an event series into a durable operating rhythm.
